# Weather by Cities

Консольное приложение на C# (.NET), которое:

1. Загружает список городов из `Cities.txt` в память.
2. Для каждого уникального города получает погоду через API `https://wttr.in/{City}?format=j1`.
3. Сохраняет данные в модель `WeatherData` (город, текущая температура в °C, страна).
4. Выводит информацию по каждому городу, например: `Tokyo, Japan +18 °C`.
5. Группирует города по странам и выводит количество городов, среднюю, минимальную и максимальную температуру,
   например: `Japan — 3 cities, avg: +19 °C, min: +16 °C, max: +22 °C`.

Для JSON используется только `System.Text.Json`, сторонние пакеты не подключаются.

## Запуск

Нужен .NET SDK 10.

```
cd WeatherApp
dotnet run
```

Файл `Cities.txt` ищется в текущей папке и в папках выше. Можно указать путь явно:

```
dotnet run -- path/to/Cities.txt
```

## Структура

- `Cities.txt` — исходный список городов
- `WeatherApp/WeatherData.cs` — модель данных и форматирование температуры
- `WeatherApp/Program.cs` — загрузка файла, запросы к API, вывод и группировка
